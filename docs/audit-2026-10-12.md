# Dealstash audit — October 12, 2026

Scope: code review of saving, underwriting recovery, email intake, tenant filters, exports, and landing-page consistency. This is not a signed-in production or database audit.

## Fixed in this pass

- Deal field updates no longer report success when the firm-scoped update affected no record.
- Underwriting worker selects only running/failed parent runs before limiting pending steps, preventing finished or paused runs from crowding out active work. Query errors return a failure instead of an empty successful sweep.
- CSV, Excel, and Export Ready use the same 1–5 to 0–100 score calculation as the application (a rating of 3 maps to 50, not 60).
- Missing Excel financial values remain blank rather than becoming zero; real zeroes are preserved.

## Open findings

1. High: underwriting recovery is scheduled once daily (`0 5 * * *`). Interrupted runs can wait almost a day for recovery. Confirm hosting plan and configure frequent background execution before promising unattended runs. Existing per-sweep limits also require capacity monitoring as usage grows.
2. High: email intake logs financial snapshot insert errors and ignores file metadata insert results. It can mark the receipt processed after incomplete persistence. Retries return an existing deal immediately, so they do not repair missing child records. Address with idempotent child-record reconciliation and explicit partial-failure status.
3. Medium: exports discard errors from related-record queries and can produce an incomplete workbook/CSV that appears successful. Return a retryable error when required queries fail.
4. Medium: notes are serialized within one editor, but two teammates editing the same section still use last-write-wins. Consider optimistic concurrency and a conflict prompt.
5. Development dependencies: prior full dependency audit reported five high warnings through the ESLint dependency chain. Production dependency audit was clean after the security patch. Do not apply the suggested forced downgrade without compatibility review.
